AI HealthGuard - Project
========================

This package contains the Flask project files. Before running, add your icon images:

Put these files inside: static/images/
 - app_icon.png        (recommended 192x192)
 - app_icon_big.png    (recommended 512x512)
 - favicon.png         (any size, e.g., 32x32)

Run:
$ python app.py

The app will be available at http://127.0.0.1:5000/

Uploads (images/audio) will be saved under static/uploads/
